# 08 — 「跳过」按钮不再骗人

**What to build:** 用户点浮层上的「跳过」时，要么真的发生点什么，要么这个按钮根本不出现。今天它无条件显示，而在模型驱动的引导下宿主对它是空操作——按钮点了什么也不发生，侧栏却记一笔「跳过」。旧实现退场之后所有引导都由模型驱动，这个按钮就一直在骗人。

**Blocked by:** 06

- [x] **不发明新的跳过语义**。让归约器记住「别再提这个」是另一件事：重新规划会把用户刚拒绝的那一步原样递回来，而归约器今天没有可以记录它的地方
