# 09 — 单写者断言改成断言调用点，并且自检

**What to build:** 那条守护「归约器只有一个写入者」的架构断言重新真的在守。今天它是假绿：正则匹配不到任何一行真实的 import，而且它断言的是 import 而不是调用——被它点名的那个模块满足了 import 断言却一次都没调用过。

**Blocked by:** 06

**Status:** done

- [x] 断言改为「谁调用了归约器的入口函数」，不再是「谁 import 了它」——一个 type-only 的 import 不能满足它
- [x] 断言指向真正的那个单写者（06 之后它是唯一剩下的那个宿主模块）
- [x] **给断言本身加一条前置断言：它在当前源码上必须至少匹配到一处。** 今天的失效形态是「匹配不到 → 断言集合为空 → 通过」，加上这一条之后同样的失效会红
- [x] 有一条测试证明「把入口函数的第二个调用点加进另一个模块」会让断言变红
- [x] `npm run verify` 全绿
