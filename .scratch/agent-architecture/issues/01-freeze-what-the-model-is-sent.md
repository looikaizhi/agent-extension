# 01 — 冻结「发给模型的东西」快照

**What to build:**

动任何结构之前，先为两个 Agent 各生成一份「发给模型的东西」的快照，逐字节存进仓库。

- 对一组固定输入，记下三样：system 消息、给模型的回答形状（引导：工具 schema；问答：带信封形状说明的那条 system 消息）、user 消息。
- 之后规格 A 的每一张票都要求与它逐字节一致。本规格里没有任何一张票被允许改变模型看到的东西。
- 输入：
  - golden 语料里每一条引导调用的目标与元素表；
  - 问答那侧：问答 golden 语料里只有手写的回答，没有问题和元素表，所以用构造的问题配上引导 golden 语料里的元素表；
  - 构造输入，专门覆盖：有历史（含已确认、点了没到、目标消失，以及落点）、有站点知识（github 域名）、有新出现的 ref、元素表被截断、非中文的目标。

**Blocked by:** None — can start immediately
