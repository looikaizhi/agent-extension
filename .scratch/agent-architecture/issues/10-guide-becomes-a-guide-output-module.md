# 10 — guide 成为引导的 Output 模块

**What to build:**

最大的那一块。guide 回答的全部东西搬进它自己的 `Output` 模块：

- 给模型的形状（步骤、路标、上一步结果）；
- 识别；
- 它专有的校验（ref 在表内、动作合法、输入值只给能输入的控件等）；
- 提示词里它那段门槛；
- 后果：落成步骤、首步跨站先确认、打转兜底；
- trace 摘要。

做完之后，归约器里只剩分派与 Thread 级的规矩。

- [x] 系统提示词里工具选择那一段的开头与结尾（「四个工具对应四种回答」与「route 只描述…」）归到 agent 级的说明，不跟任何一个模块走

- **模块接口两处变化**：
