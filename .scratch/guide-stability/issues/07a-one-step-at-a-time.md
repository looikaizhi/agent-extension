# 07a — 一次一步:`point` 取代 `guide`

**What to build:**

模型一次只指一步。

今天模型可以一次返回任意多步,而超时前进时推进游标却不盖章,那条历史永远停在未知——这是「做成了的一步被记成没做成」的一条根本路径。一次一步在现有的唤醒路径上就能成立:点开一个对话框,页面原地变了,触发器照旧提交新表、唤起下一次调用,模型在新表上指下一步。所以这张票不需要工具循环。

**Blocked by:** None — can start immediately
