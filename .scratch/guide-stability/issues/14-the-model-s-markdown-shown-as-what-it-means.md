**进度记录**(2026-09-20):

- **量过再做**:13 轮真机日志里,引导的 `why`(1078 条)和 `question`(14 条)只有 2 条带了标记;问答冒烟的两条回答都用了加粗、列表、行内代码、空行分段。所以认的就是这四样,别的不认。
- **解析** `src/shared/prose.ts` 的 `readProse`:把文字读成段落和列表,行内只有文字、行内代码、加粗(加粗里可以有行内代码)。配不上对的标记照原文留着;加粗要贴着字(`2 ** 3 ** 2` 是算式);`(1) …` 这种编号不是列表;缩进的续行归上一项,缩进的子列表并进同一个列表。只产出结构,从不产出标记。单测 15 条,含真机那条回答原文。
- **两处显示**:侧栏 `Prose.tsx` 用 React 元素;浮层 `overlay.ts` 的 `writeProse` 用 `createElement` 和文本节点。浮层的消息卡片(回答、问题、提示、收场说明)和步骤卡片的说明都走它;浮层的调试读数带上卡片渲染后的样子(`message.rendered`),e2e 由此核对。侧栏的状态行从 `<p>` 改成 `<div>`(里面要放段落和列表),e2e 的三处选择器随之改。
- **样式**:段与段、段与列表之间 6px;行内代码等宽、浅底。第一次截图发现块间距没生效——清零 margin 的选择器比加间距的更具体,改用 `:where()` 把清零那条降到零特异性。侧栏「为什么是这一步:」后面紧跟第一段,不另起一行。
- e2e 新增 Q-1b:一条带加粗、列表、行内代码,并引了一段 `<img … onerror>` 的回答——侧栏和浮层都按意思显示,星号和反引号不再露出,那段 HTML 只是文字,页面上什么都没执行。修之前三条红(「什么都没执行」原本就绿,因为原先是 `textContent`)。
