# 10c — 侧栏关着时,浮层自己把话说清楚

**What to build:**

侧栏关着,用户看着页面,也能知道引导在说什么、在等什么。今天 `ask` 的问题、`explain` 的回答、跨站确认、收场原因(「看起来已经到了」「调用失败」)只在侧栏里出现;侧栏关着时,浮层上只有「需要你先选一个」「依据」几个字,跨站那一步干等着,收场时浮层直接消失。

> **2026-09-19 由全面审计产生,用户定**:浮层卡片上都说。侧栏开着时侧栏照旧也说。
